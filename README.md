# Anti-Slop

A reference library of AI writing patterns.

Language models trained on very different texts still produce prose that sounds alike. The same phrases, sentence shapes, transitions and openers show up across topics and formats. Anti-Slop documents these patterns, shows how they appear in writing, and notes how they vary between models.

## Read the library

The full library is in [anti-slop-library.md](anti-slop-library.md).

## What it covers

The library has 18 patterns:

1. Contrastive parallelism / mirrored contrast
2. Teaser sentences / delayed context
3. Contextually incongruent wording
4. Anthropomorphic AI language
5. Rule-of-three
6. Vagueness
7. Conjunction-led sentence openers
8. Repetitive sentence openings
9. Repetitive vocabulary
10. Punctuation and sentence-length monotony
11. Filler transitions
12. Participial phrase overuse
13. Roundabout framing
14. Overgeneralization
15. Formulaic hooks and openers
16. Conditional negation
17. Incomplete sentence constructions
18. Passive voice and third-person detachment

It tracks two kinds of patterns: those common across models such as Claude, GPT and Gemini, and those tied to a specific model or version.

## How to use it

- Use it to recognise patterns. Don't use it as a list of banned phrases.
- The examples are illustrative. Models can swap in new wording and keep the same underlying construction, so filtering exact phrases won't remove a pattern.
- Most of these constructions are legitimate in human writing. The problem is how often they appear and how predictably they are placed.
- Some patterns include editorial questions to ask while revising. Others only describe the behaviour. This is deliberate, so writers don't trade one formula for another.

## Status

This is a living document. New patterns, variations and model-specific observations will be added as models change.
